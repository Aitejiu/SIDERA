# SIDERA

开发者的多 Agent 任务中控台。

任务进行到哪了，哪一块卡住了，什么时候需要你介入？SIDERA 把分散的 Agent
工作整理成可以逐层查看的任务空间，让你先掌握进展，需要时再深入执行细节。

## 从任务出发，掌握每一块进展

- **先看全局。** 在任务列表查看整体进度和需要处理的事项，进入任务定位具体子任务的卡点。
- **按需深入。** 按“任务 → 子任务 → WorkerItem”逐层打开。WorkerItem 是一位 Worker 的工作空间，集中呈现当前步骤、工作记录和你的介入消息。
- **两种视角。** 用看板查看谁在执行、谁在等待；切换 DAG 查看并行关系和前后依赖。
- **随时介入。** 在对应工作空间补充要求或纠正方向，并保留介入记录。单点介入与整体需求变更分开处理。
- **细节不抢占主界面。** 需要排查时再打开 Agent Trace，查看具体事件及输入输出；多个任务可以在独立标签中切换。

## 开始体验

当前提供 macOS 本地 Demo，无需模型 API key。跟随[快速开始](docs/deployment/initial-demo.md)
安装并启动后，即可用样例任务体验看板、DAG、WorkerItem、介入记录和 Trace。

第一次打开可以按这个顺序浏览：

1. 在任务列表打开“支付重构”，查看整体进展和需要关注的子任务。
2. 进入“回调幂等”，用看板查看各 Worker 的状态，或切换 DAG 查看依赖。
3. 打开“实现者”的工作空间，查看步骤、工作记录和介入位置，再按需打开 Trace。

完整的页面操作见[使用指南](docs/guide/workspace.md)。

> 当前 Demo 使用样例数据，不会自动调用模型执行新任务。介入可以保存，但不会交给真实
> Worker 处理；主 Agent 聊天与外部消息通道需要单独配置。此版本仅供本机单人体验，
> 尚未完成完整真实链路验收，请勿直接部署到公网。
